# Institutional Excellence (Modern & Formal) ## Product Overview **The Pitch:** A unified research portal for BRIN integrating deep learning models with a streamlined web interface. It allows researchers to upload data, execute neural network predictions, and securely manage results within an institutionally sanctioned environment. **For:** BRIN researchers and data science students who need a reliable, high-performance web interface to run complex deep learning models without writing scripts. **Device:** desktop **Design Direction:** Formal academic rigor meets modern data science. Highly structured grids, striking BRIN-red accents, and technical typography convey authority, accuracy, and institutional trust. **Inspired by:** CERN Open Data Portal, MIT MITRE dashboards. --- ## Screens - **Landing Page:** Public-facing single page featuring BRIN's mission, animated network motifs, and a call-to-action for researchers. - **Login Portal:** Secure, distraction-free authentication gateway for institutional credentials. - **User Dashboard - Upload:** Drag-and-drop staging area for datasets awaiting neural network processing. - **User Dashboard - Prediction Results:** Technical readouts of deep learning outputs with confidence scores and management actions. - **Admin Dashboard - Users:** Access control matrix for approving or revoking researcher credentials. - **Admin Dashboard - Models:** Version control and performance metrics for deployed deep learning models. --- ## Key Flows **Model Execution Flow:** Researcher uploads data and runs prediction. 1. User is on **User Dashboard - Upload** -> sees drag-and-drop zone 2. User drops `.csv` or `.png` file and clicks **Run Model** -> progress bar initiates, status changes to "Processing" 3. UI routes to **User Dashboard - Prediction Results** displaying confidence heatmaps and a **Save to Archive** action ---
Design System ## Color Palette - **Primary:** `#B91C1C` - BRIN Red (Buttons, active states, progress bars) - **Background:** `#F8FAFC` - Cool slate off-white (Page background) - **Surface:** `#FFFFFF` - Crisp white (Cards, modals, navigation) - **Text:** `#0F172A` - Deep midnight blue (Headings, primary body text) - **Muted:** `#64748B` - Steel gray (Secondary text, inactive tabs, subtle borders) - **Accent:** `#0369A1` - Academic blue (Informational highlights, secondary data points) ## Typography - **Headings:** `Lora`, 700, 24-48px (Authoritative, academic serif) - **Body:** `IBM Plex Sans`, 400, 16px (Technical, highly legible sans-serif) - **Small text:** `IBM Plex Sans`, 400, 13px (Data tables, footnotes) - **Buttons:** `IBM Plex Sans`, 600, 14px (Crisp, commanding uppercase) **Style notes:** Sharp corners (`0px` radius on all cards and buttons). Thin, solid borders (`1px solid #E2E8F0`). Drop shadows are completely eliminated in favor of strict border separation to emphasize a flat, technical, paper-like aesthetic. ## Design Tokens ```css :root { --color-primary: #B91C1C; --color-background: #F8FAFC; --color-surface: #FFFFFF; --color-text: #0F172A; --color-muted: #64748B; --color-accent: #0369A1; --font-heading: 'Lora', serif; --font-body: 'IBM Plex Sans', sans-serif; --radius: 0px; --spacing: 8px; } ```

Screen Specifications ### Landing Page **Purpose:** Public entry point communicating BRIN's deep learning capabilities and onboarding researchers. **Layout:** Single long-scroll page with fixed top navigation. Hero section, followed by "About the Models", and "Join Research" sections. **Key Elements:** - **Fixed Header:** 64px height, `#FFFFFF` background, bottom border `1px solid #E2E8F0`. Left: BRIN Logo. Right: Anchor links (Home, About, Join) and a solid `#B91C1C` Login button. - **Hero Section:** 800px height. Left: `Lora` 48px heading "Advancing Indonesian Research through Deep Learning". Right: WebGL animated neural network mesh (dots and connecting lines fading in/out). - **Join Research Form:** Strict grid layout with input fields (First Name, Last Name, Institution, Email). Solid `#B91C1C` submit button. **States:** - **Empty:** N/A - **Loading:** Skeleton mesh replaces WebGL animation during initial load. - **Error:** N/A **Components:** - **Section Heading:** `Lora`, 700, 32px, `#0F172A`, followed by a 40px `#B91C1C` horizontal divider line. **Interactions:** - **Click Anchor Link:** Smooth scroll to respective section (`scroll-behavior: smooth`). - **Hover Login Button:** Background darkens to `#991B1B`. **Responsive:** - **Desktop:** 1200px max-width container, 12-column grid. - **Tablet:** 8-column grid, Hero text and animation stack vertically. - **Mobile:** 4-column grid, hamburger menu for navigation. ### Login Portal **Purpose:** Secure entry for authorized researchers and admins. **Layout:** Split screen. Left 40% is the login form. Right 60% is a static hero image of the BRIN facility overlaid with a `#B91C1C` multiply blend. **Key Elements:** - **Login Container:** Centered in the left pane. 400px width. - **Credentials Form:** Email and Password inputs. Labels in `IBM Plex Sans`, 600, 13px. Inputs have a `1px solid #94A3B8` border, `48px` height. - **Submit Action:** Full width, 48px height, `#B91C1C` background, white text "AUTHENTICATE". **States:** - **Empty:** Fields blank, button disabled (`#CBD5E1` background). - **Loading:** Button text replaces with a spinning `#FFFFFF` dashed circle. - **Error:** `1px solid #B91C1C` red border on inputs, 13px red text "Invalid institutional credentials" below password. **Components:** - **Input Field:** 48px height, `#FFFFFF` bg, `16px` text, `16px` left padding. **Interactions:** - **Focus Input:** Border changes to `2px solid #0F172A`. **Responsive:** - **Desktop:** Split screen layout (40/60). - **Tablet:** Right side image hidden, form centered on screen. - **Mobile:** Full width form, 16px side padding. ### User Dashboard - Upload **Purpose:** Workspace for researchers to upload data and trigger neural network models. **Layout:** Sidebar navigation (240px) on the left, main content area (fluid) on the right. **Key Elements:** - **Sidebar:** `#FFFFFF` background. Links: New Prediction, History, Settings. Active link has a `4px` `#B91C1C` left border. - **Model Selector:** Dropdown menu to select the target model (e.g., "ResNet-50 Image Classifier", "LSTM Time Series"). - **Dropzone:** 400px height, dashed `2px` border (`#94A3B8`), `#F8FAFC` background. Centered icon and text: "Drag data files here or browse". **States:** - **Empty:** Dropzone shows instruction text. - **Loading:** Progress bar (`#B91C1C`) appears inside dropzone showing file upload percentage. - **Error:** Dropzone background turns `#FEF2F2`, text shows "Unsupported file format. Use .csv or .png". **Components:** - **Upload Button:** Secondary style, `#FFFFFF` bg, `1px solid #0F172A` border, text `#0F172A`. **Interactions:** - **Drag Over Dropzone:** Border changes to solid `#B91C1C`, background turns white. - **Click Run:** Routes to Prediction Results. **Responsive:** - **Desktop:** Sidebar + Main content. - **Tablet:** Sidebar collapses to icons only (80px). - **Mobile:** Sidebar hidden behind a drawer menu. ### User Dashboard - Prediction Results **Purpose:** Display AI analysis outputs, confidence levels, and allow users to save or discard results. **Layout:** Sidebar left, top header with actions, main grid displaying data and visual outputs. **Key Elements:** - **Action Header:** Right-aligned buttons: "Cancel/Delete" (Secondary, gray text) and "Save to Archive" (Primary, `#B91C1C`). - **Results Matrix:** A 2-column grid. Left: Input visualization (e.g., image or graph). Right: Key-value pairs of output metrics (Prediction Class, Confidence %, Processing Time). - **Confidence Bar:** Horizontal bar chart. Fill color depends on value (>90% `#059669`, <90% `#B91C1C`). **States:** - **Empty:** N/A (unreachable without data). - **Loading:** Pulsing gray rectangles over metrics (Skeleton UI). - **Error:** Banner at top indicating "Model timeout. Please retry." **Components:** - **Metric Card:** `#FFFFFF` bg, `1px solid #E2E8F0`, 16px padding. Title in `13px` uppercase muted text, Value in `24px Lora`. **Interactions:** - **Click Save:** Success toast appears bottom right: "Result appended to institutional archive". - **Click Delete:** Modal prompts "Are you sure you want to discard this prediction?". **Responsive:** - **Desktop:** 2-column results matrix. - **Tablet:** Matrix stacks vertically. - **Mobile:** Matrix stacks vertically, smaller fonts. ### Admin Dashboard - Users **Purpose:** Centralized user management for IT administrators to govern platform access. **Layout:** Sidebar left, main content with search/filter bar and a dense data list. **Key Elements:** - **Filter Bar:** Search input, "Role" dropdown (Admin, Researcher), and "Status" dropdown (Active, Pending). - **User List:** Strict row-based layout (no table borders, just bottom borders per row). Columns: Name, Department, Email, Role, Last Active, Actions. - **Action Menu:** Vertical ellipsis opening a dropdown (Edit, Revoke Access, Reset Password). **States:** - **Empty:** "No researchers match current filters." - **Loading:** Rows replaced by skeleton lines. - **Error:** "Unable to fetch directory data." **Components:** - **Status Badge:** Text only, preceded by a colored dot (Green for active, Yellow for pending). `13px` IBM Plex Sans. **Interactions:** - **Hover Row:** Row background shifts from `#FFFFFF` to `#F1F5F9`. - **Click Revoke:** Row grays out, status changes immediately to "Revoked". **Responsive:** - **Desktop:** All columns visible. - **Tablet:** Hide "Last Active" column. - **Mobile:** Convert rows to stacked cards. ### Admin Dashboard - Models **Purpose:** Oversight of deployed deep learning models, versions, and performance accuracy. **Layout:** Grid of model summary cards, followed by detailed deployment logs. **Key Elements:** - **Model Cards:** Spanning a 3-column grid. Each displays: Model Name (Lora, 18px), Current Version (`v2.1.0`), Status (Online/Offline), and Accuracy Metric (`94.2%`). - **Deploy Button:** Floating top right, "Deploy New Version", primary `#B91C1C` button. - **System Logs:** A terminal-like black box (`#0F172A` bg) at the bottom showing real-time model inference logs in monospace green font. **States:** - **Empty:** "No models currently deployed." - **Loading:** Spinning indicator in place of accuracy metrics. - **Error:** Offline models show a red border (`2px solid #B91C1C`). **Components:** - **Log Window:** 200px height, `overflow-y: scroll`, `font-family: monospace`, `12px` text. **Interactions:** - **Click Model Card:** Expands to show version history and rollback options. **Responsive:** - **Desktop:** 3-column card grid. - **Tablet:** 2-column card grid. - **Mobile:** 1-column card grid, log window hidden.

Build Guide **Stack:** HTML + Tailwind CSS v3 **Build Order:** 1. **Design System & Typography:** Set up `IBM Plex Sans` and `Lora` in `tailwind.config.js`. Define strict `0px` border radius rules. 2. **Login Portal:** Establishes the exact aesthetic for forms, inputs, and strict grid spacing without layout distractions. 3. **User Dashboard - Upload:** Sets the precedent for the sidebar layout, navigation states, and drag-and-drop interactions. 4. **User Dashboard - Prediction Results:** Implements data visualization, metric cards, and secondary UI components. 5. **Admin Dashboards:** Reuses metric cards and layout from the user dashboard, focusing on lists and data density. 6. **Landing Page:** Built last as it introduces unique elements (WebGL animation, anchor scrolling) that are not needed in the core application logic.
